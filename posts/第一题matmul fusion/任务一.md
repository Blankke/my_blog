这个任务可以这么理解：也就是LoRA的思想

![[Pasted image 20260506205930.png|500]]
```c
输入 X: [M, H]
 算子1 (降维): Y = X @ A          其中 A: [H, r], Y: [M, r] 
 算子2 (升维): Z = Y @ B          其中 B: [r, H'], Z: [M, H'] 
 算子3 (主干): W = X @ C         其中 C: [H, H'], W: [M, H'] 
 最终输出: O = W + Z 即 O: [M, H']
 O=X @ C+X @ A @ B
```

所以这里让我融合算子2、3，也就是做一个算子
$O=X \cdot C + Y\cdot B$
其中T是`X@A`提前算好的.
SGLang 会把原本 checkpoint 里的 gate_proj 和 up_proj 都归一化到 gate_up_proj 这个 fused 名字上：所以只有gate_up这一个参数
融合思路：在主干GEMM kernel的每个thread block完成对应tile的计算后，将升维矩阵乘对应tile的结果直接累加到输出上，避免中间结果经过HBM
>[!note]
>**HBM = High Bandwidth Memory，高带宽显存。**
在 GPU 里，它通常就是我们说的 **global memory / GPU 显存**。例如 A100、H100 上的显存就是 HBM。
